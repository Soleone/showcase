# showcase

The instructions live in the CLI, so they always match the installed version. Run:

```sh
showcase guide    # or: npx @soleone/showcase guide
```

and follow it. It lists topics you read only when a step needs them (`showcase guide <topic>`), and every failing `showcase check` names the topic that helps.
